# STUCHECK AI 🔍

## AI-Powered Student Document Verification System

STUCHECK AI is an AI-assisted web application designed to automate
student document verification. The system extracts information from
student marksheets using OCR and compares the extracted data with
authentic records stored in a MySQL database.

---

## 🚀 Features

- 📄 Student marksheet upload
- 🔍 OCR-based text extraction
- 🧠 Automatic student information extraction
- 🗄️ MySQL database verification
- 👤 Student name verification
- 🆔 Certificate number verification
- 📊 Total marks verification
- 🏆 Result verification
- 📈 Verification score generation
- ✅ Verified / ❌ Not Verified status
- 🌐 Flask-based web interface
